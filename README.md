# Teambuilder Test Task

## Tasks Completed

1. **Sort by Price**

   - On the first page, a dropdown allows sorting products by price: "Low to High" and "High to Low".

2. **Yen Price Format**

   - Product prices are formatted in Japanese Yen (e.g., "¥2,999").

3. **3x4 Product Grid**

   - Products arrangement changed from 4x3 to 3x4 grid on the homepage.

4. **Product Detail Page**
   - "Buy Now" button is displayed next to "Add to Cart".
   - Below-product horizontal list flows from right to left.
